Diplom_3

Выпускной проект. Задание 3: Mодель страниц (Page Object Model)
Тестирование веб-приложения Stellar Burgers.
Структура проекта:

locators - директория содержит файлы с локаторами для различных страниц сайта https://stellarburgers.nomoreparties.site/

pages - директория, в которой хранятся методы страниц сайта.

tests - пакет, содержащий тесты, разделенные по классам:

test_feed_page.py  

   Раздел «Лента заказов»  
   Проверки:
По клику на заказ открывается всплывающее окно с деталями.

Заказы пользователя из раздела «История заказов» отображаются на странице «Лента заказов».

При создании нового заказа увеличивается счетчик «Выполнено за всё время».

При создании нового заказа увеличивается счетчик «Выполнено за сегодня».

После оформления заказа его номер отображается в разделе «В работе».

test_forgot_password_page.py  

   Восстановление пароля  
   Проверки:
Переход на страницу восстановления пароля по нажатию кнопки «Восстановить пароль».

Ввод email и клик по кнопке «Восстановить».

Клик по кнопке «Показать/Скрыть пароль» активирует поле ввода — подсвечивает его.

test_main_page.py  

   Основной функционал  
   Проверки:
Переход по клику на «Конструктор».

Переход по клику на «Лента заказов».

По клику на ингредиент открывается всплывающее окно с деталями.

Всплывающее окно закрывается по клику на крестик.

При добавлении ингредиента в заказ увеличивается счетчик этого ингредиента.

Залогиненный пользователь может оформить заказ.

test_profile_page.py  

   Личный кабинет  
   Проверки:
Переход по клику на «Личный кабинет».

Переход в раздел «История заказов».

Выход из аккаунта.

conftest.py  

   Содержит фикстуру create_user.
Также в корневом каталоге проекта находятся:

файл data.py с тестовыми данными,

файл requirements.txt с зависимостями проекта,

файл .gitignore.
Запуск автотестов:

Установка зависимостей  
bash

 Копировать код
$ pip install -r requirements.txt
Генерация Allure-отчёта  

bash

 Копировать код
$ pytest tests --alluredir=allure_results
$ allure serve allure_results
